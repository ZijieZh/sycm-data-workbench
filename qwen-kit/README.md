# 千问办公复赛网页制作材料包

这套材料用于让千问办公制作并发布“生参数据工作台”的复赛展示网页。

使用顺序：

1. 将 `01_一键提示词.md` 全文复制给千问办公。
2. 将 `02_页面原材料.md`、`03_演示数据.json` 作为参考材料一并提供。
3. 让千问先生成网页，再要求它检查移动端、链接、脱敏和事实一致性。
4. 发布后使用 `04_发布验收清单.md` 自查，再提交赛事官网。

网页定位：从生意参谋页面取数，到 DuckDB 建库，再到 BI 经营分析的一站式工作流展示。

公开名称统一使用“生参旗舰店”。不要写入真实店铺名称、真实店铺 ID、真实经营数据、账号凭证、本机路径或未经证实的用户评价。
