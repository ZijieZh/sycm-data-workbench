DATABASE STARTER

数据库不是一个文件，而是一套可持续更新的方法

教学包提供虚构 Excel、导入脚本、质量校验、事实表、分析视图和只读 MCP 示例。先校验，再写库；每一次更新都能追溯到源文件与批次。

阅读搭建教程运行示例模板 →
PowerShell
# 1. 检查源文件，不写库
python scripts/import_data.py \
  --source data/示例月度销售.xlsx \
  --validate-only

# 2. 校验通过后写入 DuckDB
python scripts/import_data.py \
  --source data/示例月度销售.xlsx \
  --write-db

# 3. 验证自然键、汇总与只读连接
python scripts/verify_database.py
源数据不覆盖原始导出只归档，任何清洗都可回溯。
