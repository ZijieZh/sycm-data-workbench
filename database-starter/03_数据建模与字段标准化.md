# 数据建模与字段标准化

## 表命名

| 前缀 | 用途 | 示例 |
|---|---|---|
| `fact_` | 标准化事实明细 | `fact_sales_monthly` |
| `mart_` | 面向业务查询的分析表或视图 | `mart_sales_monthly` |
| `dim_` | 维度映射与标准枚举 | `dim_product` |
| `etl_` | 导入批次与质量审计 | `etl_import_batch` |

## 字段标准

| 类型 | 推荐格式 | 示例 |
|---|---|---|
| 日期 | DuckDB `DATE` | `2026-07-01` |
| 月份 | `VARCHAR`，`YYYY-MM` | `2026-07` |
| 金额 | `DOUBLE`或`DECIMAL` | `1250.50` |
| 数量 | `BIGINT` | `12` |
| 比例 | 小数存储 | `0.1539`表示15.39% |
| 布尔 | `BOOLEAN` | `true` |
| 标识 | `VARCHAR` | 保留商品ID前导零 |
| 导入时间 | `TIMESTAMP` | `2026-09-01 10:30:00` |

## 标准化流程

1. 去除字段名前后空格和换行，按字段映射表重命名。
2. 标识字段统一转为字符串。
3. 日期字段解析为日期，月份派生为`YYYY-MM`。
4. 金额和数量去除千分位、单位和空白后转为数值。
5. 百分比统一转为小数。
6. 名称字段通过别名字典映射为标准名称。
7. 空字符串、`-`、`/`和平台特殊值按业务规则转换为状态或空值。
8. 增加来源文件、来源sheet、来源行号、导入批次和导入时间。

## 指标可加性

| 指标类型 | 聚合方式 | 示例 |
|---|---|---|
| 可加指标 | 求和 | GMV、销量、退款金额 |
| 半可加指标 | 固定粒度后求和 | 库存、账户余额 |
| 去重指标 | 在目标粒度重新去重 | 买家数、访客数 |
| 比率指标 | 汇总分子/汇总分母重算 | 转化率、退款率 |
| 均值指标 | 汇总金额/汇总数量重算 | 客单价、件单价 |

## 自然键设计

自然键来自业务事实的唯一性，而非Excel行号。常见示例：

- 商品月度：`统计月份 + 店铺 + 商品ID`
- 店铺分日：`统计日期 + 店铺 + 仓 + 数据类别`
- 订单明细：`平台 + 订单ID + 子订单ID`
- 营销关键词：`统计月份 + 品牌 + 关键词 + 类型`

同一自然键出现多行时，先判断完全重复、业务拆分还是来源冲突，再明确保留、聚合或阻断规则。
